**（一）基本概念**

**1. 基本概念介绍**

**关键事件节点识别**：指通过定量化评估方法从事件网络中识别出对网络结构和功能具有显著影响力的事件节点。

**网络拆解**：指以最小的代价（即移除尽可能少的节点或边），最大化地破坏事件网络的连通性，使其功能瓦解、结构碎片化。

> **1.1 基于自监督学习的****节点重要性评估**

本项目提出一种融合网络拆解与图对比学习的节点重要性评估方法，从而克服传统拓扑指标无法量化功能破坏性、以及监督学习依赖高成本人工标注的局限，如图3所示。在拓扑层面，通过网络拆解识别最小破坏集，精准定位引发网络连通性崩溃的结构性关键节点，生成反映全局拓扑重要性的高置信度标签；在语义层面，引入图对比学习机制，通过模拟真实事件网络中常见的噪声与干扰，迫使模型在动态变化中学习稳定的核心语义特征，以精准识别出那些在战略意图、功能角色等维度具有关键作用的节点。网络拆解与图对比学习相结合，实现了事件节点“结构脆弱性”和“语义鲁棒性”的深度融合，二者融合形成可靠的节点重要性评估，用于指导关键事件节点挖掘。

> **1.1.1基于网络拆解的拓扑评分**
>
> 本项目基于网络拆解,以最大连通组件（Giant Connected Component,
> GCC）作为网络连通性的核心评测指标来评估节点的拓扑重要性分数，其计算过程分为两步。

**（1）搜索最小网络拆解集合。**在给定的网络中，我们需要寻找出规模最小的关键节点集合，当该集合被移除后，剩余网络的最大连通组件尺寸将缩减至预定义的阈值以下（例如，设定阈值$`\Theta`$
= 1%）。该优化问题可形式化表述为：

``` math
V^{\ast} = \min\left\{ V_{t} \subseteq V:\frac{\left| G \smallsetminus V_{t} \right|}{N} \leq \Theta \right\}
```

其中，$`V_{t}`$为待移除节点集，
$`\left| G\backslash V_{t} \right|`$为移除后GCC的节点数， $`N`$为原网络总节点数。

**（2）生成拓扑评分。**在识别出所有满足条件的最小拆解集合的基础上，统计每个节点在集合中出现的频次，并进行归一化处理，得到节点的初始拓扑重要性分数。为进一步捕捉节点在其局部邻域内的影响力，我们设计了一种分数传播机制：将上述初始分数沿边进行扩散，使节点聚合来自一阶邻居的拓扑信息。利用该分数传播机制传播节点的初始拓扑重要性分数，最终生成每个节点的拓扑重要性评分。

**1.1.2基于图对比学习的语义评分**

项目采用图对比学习（Graph Contrastive
Learning）进行节点语义的重要性评估，其核心流程分为三个步骤。

**（1）事件语义编码**。鉴于台海事件文本数据呈现出短文本稀疏性、领域术语高密度性和情报语义模糊性等特定，本研究选用
RoBERTa (Robustly Optimized BERT Pretraining Approach)
预训练模型构建事件节点的深度语义编码。依托于大规模语料库的预训练以及动态掩码（Dynamic
Masking）机制的引入，RoBERTa有效克服了 Word2Vec 与标准 BERT
在短文本语义建模中的局限，尤其在细粒度概念消歧上表现突出，能够精准区分“侦察”与“监视”、“协防”与“介入”等高混淆度术语的微小语义差异。该模型对节点原始文本X进行编码，并提取
\[CLS\] 标记对应的 768 维上下文向量，作为节点的初始语义表征：$`
`$
``` math
\mathbf{H} = RoBERTa(X)
```

其中 $`\mathbf{H} \in \mathbb{R}^{|V| \times d}`$为节点语义特征矩阵，d 为特征维度。

**（2）训练图对比学习编码器。**通过构建语义与结构的双重扰动视图进行对抗式训练，促使模型在噪声环境中捕捉具有强鲁棒性的语义不变性特征，从而显著增强了关键节点识别的精确度与抗干扰性能。对原始图
G=(V,E,H)
构造两个增强视图$`{\widetilde{G}}^{(1)}`$与$`{\widetilde{G}}^{(2)}`$：在语义层面，对RoBERTa输出的节点特征 H进行随机维度掩码，模拟语义层面的信息缺失；在结构层面，以固定概率随机丢弃边集 E 中的连接，模拟网络观测中的链路缺失与不确定性。通过这种双重独立增强策略，构建具有差异性的视图对，为模型提供充分的噪声环境。随后，将两视图分别输入到共享参数的图编码器中，生成节点嵌入
$`\mathbf{z}_{i}^{(1)}`$ 与
$`\mathbf{z}_{i}^{(2)}`$​。为度量同一节点在不同视图下的表示一致性，采用余弦相似度作为相似性函数：

``` math
sim\left( \mathbf{z}_{i}^{(1)},\mathbf{z}_{i}^{(2)} \right) = \frac{\left( \mathbf{z}_{i}^{(1)} \right)^{\top}\mathbf{z}_{i}^{(2)}}{\left. \parallel\mathbf{z}_{i}^{(1)} \right.\parallel \cdot \left. \parallel\mathbf{z}_{i}^{(2)} \right.\parallel}
```

在此基础上，采用 InfoNCE（Noise Contrastive
Estimation）损失函数进行优化，其目标是拉近正样本对（同一节点在两个视图下的嵌入），同时推开负样本对（与其他节点的嵌入）。具体定义如下：

``` math
\mathcal{L}_{cont} = - \frac{1}{|V|}\sum_{i \in V}^{}\log\frac{\exp\left( \sin\left( \mathbf{z}_{i}^{(1)},\mathbf{z}_{i}^{(2)} \right)/\tau \right)}{\sum_{j \in V}^{}\exp\left( \sin\left( \mathbf{z}_{i}^{(1)},\mathbf{z}_{j}^{(2)} \right)/\tau \right)}
```

其中*τ*\>0为温度超参数，用于调节分布的尖锐程度。

**（3）生成语义评分。**利用训练好的对比学习编码器，在原始图（无扰动）上执行一次前向传播，获得最终节点表示$`\mathbf{z}_{i}`$。计算节点嵌入的
L2 范数，并进行全局归一化，得到语义评分，计算公式如下：

``` math
{\widetilde{s}}_{i} = \frac{\parallel \mathbf{z}_{i} \parallel_{2}}{\max_{k \in V} \parallel \mathbf{z}_{k} \parallel_{2}}
```

> **1.1.3融合拓扑与语义评分**

为构建兼具结构脆弱性与语义鲁棒性的监督信号，将前述两个分支生成的评分进行加权求和，形成最终的节点级监督信号。

``` math
y_{i}^{pseudo} = \alpha \cdot {Score}_{ND}(i) + (1 - \alpha) \cdot {Score}_{cont}(i)
```

其中，$`{Score}_{ND}(i)`$ 是基于网络拆解与邻居传播得到的拓扑重要性评分，$`{Score}_{cont}(i)`$ 是基于图对比学习得到的语义重要性评分。$`\alpha \in \lbrack 0,1\rbrack`$
为可调超参数，用于平衡拓扑驱动与语义驱动的重要性权重。

该模型深度融合网络结构、语义功能与多元关联，实现对关键节点的精准量化、综合评估。该模型获得图数据之后，首先对节点做拓扑特征工程，获取包括但不限于度、二跳邻居数、聚类系数与局部桥系数等，用以量化节点在网络中扮演的结构角色（如枢纽、桥接点或边缘节点）。将拓扑特征工程与

**1.2.1异构图注意网络**

在异构图注意力网络的实现中，针对复杂事件网络中存在的多种语义关系，设计了基于边类型感知的参数化消息传递机制。该机制通过为每种边类型维护独立的嵌入表示和变换矩阵，实现对不同语义关系的差异化建模。

具体而言，模型为每类关系 $`r\mathcal{\in R}`$
预定义一个可学习的关系嵌入向量
$`\mathbf{e}_{r}`$​，并在消息聚合阶段将其显式注入注意力计算与特征变换过程。对于任意节点
$`i`$ 及其通过关系r连接的邻居
$`j`$，模型将关系嵌入与节点状态共同作为计算依据，进行加权聚合。该设计确保了异质关系在传播中得到差异化处理，从而保障了信息聚合的判别性。这一过程确保“因果”与“共现”等语义迥异的关系在信息传递中被区别对待，避免同质化聚合导致的语义混淆。

在此基础上，模型采用多跳层次化传播架构，通过堆叠多层异构注意力模块，逐级扩展节点的感受野。每一跳传播不仅融合直接邻居的信息，还继承前一层已整合的高阶上下文，从而逐步构建从局部邻域到全局结构的多层次表征。例如，在第一跳中，节点捕获其一阶邻居的语义-结构特征；在第二跳中，进一步融入二阶邻居的语义-结构特征；随着传播深度增加，模型能够识别跨越多个关系类型的长程依赖模式，有效刻画事件演化中的隐性关键路径。

**1.2.2双尺度影响力评分**

为全面刻画节点在复杂事件网络中的关键性，本项目设计了一个双分支评分机制，分别从局部邻域控制力与全局系统扰动潜力两个互补视角进行量化评估。

**（1）生成局部分数** $`\mathbf{s}_{\mathbf{i}}^{\mathbf{local}}`$**。**
局部分数旨在衡量节点 $`i`$
在其直接邻域内的结构中心性与信息聚合能力。具体地，给定节点 $`i`$
的深层表示 $`\mathbf{h}_{i}`$​ 及其一跳邻居集合
$`\mathcal{N}_{i}`$​，首先计算其与每个邻居
$`\mathbf{h}_{j}`$​（j∈$`\mathcal{N}_{i}`$​）的语义–结构相似度（以点积
⟨$`\mathbf{h}_{i}`$​,$`\mathbf{h}_{j}`$​⟩
度量），反映其在局部子图中的“结构亲和力”与“功能耦合度”。随后对所有邻居取平均，得到上下文一致性得分，并叠加归一化的度中心性
$`{\widetilde{d}}_{i} = d_{i}/d\_ max`$作为拓扑先验补偿（尤其在邻居数量稀疏时增强鲁棒性）。最终局部分数定义为：

``` math
s_{i}^{local} = \frac{1}{\left| \mathcal{N}_{i} \right|}\sum_{j \in \mathcal{N}_{i}}^{}\langle\mathbf{h}_{i},\mathbf{h}_{j}\rangle + {\widetilde{d}}_{i}
```

**（2）生成全局分数**
$`\mathbf{s}_{\mathbf{i}}^{\mathbf{global}}`$**。**全局分数用于评估节点$`\ i\ `$对整个网络连通性与功能完整性的潜在影响，模拟其被移除后对系统稳定性的破坏程度。为此，模型引入一个可学习的全局投影向量
p∈$`\mathbb{R}^{d}`$，通过一个共享的全连接层（FC）实现对节点高阶表示的全局敏感度加权。首先，构建节点$`\ i\ `$​​的局部-自身融合表示$`\ \mathbf{h}_{i}`$​​，即对其自身及一跳邻居的表示进行归一化求和（采用平方根缩放以缓解度偏差）：

``` math
{\widehat{\mathbf{h}}}_{i} = \frac{1}{\sqrt{\left| \mathcal{N}_{i} \right| + 1}}\sum_{j \in \mathcal{N}_{i} \cup \{ i\}}^{}\mathbf{h}_{j}
```

随后，计算该融合表示与全局投影向量的内积，作为全局影响力得分：

``` math
s_{i}^{global} = \langle\mathbf{p},{\widehat{\mathbf{h}}}_{i}\rangle = \mathbf{p}^{\top}{\widehat{\mathbf{h}}}_{i}
```

**（3）融合局部评分和全局评分。**最终的关键性评分为局部评分和全局评分的加权融合：

``` math
s_{i} = \lambda.\ \ s_{i}^{local} + (1 - \lambda){\ .\ \ s}_{i}^{global}
```

其中权重 *λ*∈\[0,1\]
为可调超参数，用于平衡局部与全局的重要性权重。该双尺度设计兼顾微观控制力与宏观脆弱性，使模型既能发现局部活跃节点，也能识别沉默但系统关键的杠杆点，显著提升在复杂对抗场景下的识别全面性与任务适配性。
